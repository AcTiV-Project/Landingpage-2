# Accounting Services Landing Page

A responsive landing page concept for an independent accounting professional. The page introduces the practice, presents its services, and gives prospective clients clear ways to get in touch.

## Project overview

This project is a lightweight, single-page website built with HTML and CSS. It uses a calm, professional visual style with a clear hero section, service cards, and a dedicated contact area. The layout adapts to smaller screens and does not require a framework or build process.

## Features

- Responsive layout for desktop and mobile screens
- Hero section with a primary consultation link
- Six accounting and financial service cards
- Contact links for LinkedIn, WhatsApp, and Instagram
- Semantic HTML landmarks and accessibility labels
- Smooth scrolling for in-page navigation

## Built with

- HTML5
- CSS3

## Run locally

No dependencies or build tools are required. Clone or download this repository and open `index.html` in a browser.

## Project structure

```text
|-- index.html   # Page content and metadata
|-- style.css    # Layout, colors, and responsive styles
`-- README.md
```

## Customize before publishing

Update the sample business name and contact details in `index.html`. In particular, replace the placeholder WhatsApp number and social profile URLs with the correct links before deploying the page.
